# האתרים של תומר

- `taklitomer/` – תקליTומר: התקליטים הנדירים בעולם ובישראל, גרפי מחיר, היסטוריה, נמכרים לפי מדינה, משחקים וחנות.
- `tomer-vintage/` – Tomer Vintage: חנות בגדי וינטאג', מגזין, סרטונים, מועדון מנויים, משחקים והגרלות.
- `ads/taklitomer-ad.mp4` – פרסומת של 5 שניות לחנות התקליטים (חנקין 8, קדימה).

## הרצה
אתרים סטטיים: פותחים את `index.html` בדפדפן, או מפעילים GitHub Pages על הענף הראשי.

## הערה על החנות, החשבונות וההגרלות
החלקים שמשתמשים במסד נתונים (חנות, הרשמה, הזמנות, מנויים, הגרלות) נשענים על היכולות של Claude Artifacts
(`window.claude.use("db")`). מחוץ ל-Claude כל התוכן, הגרפים, הסרטונים והמשחקים עובדים, אבל החלקים האלה מציגים מסך "לא זמין".
כדי שיעבדו באתר עצמאי צריך לחבר מסד נתונים כמו Firebase או Supabase.
